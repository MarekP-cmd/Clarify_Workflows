# Release integrity records

These sidecars came from the verified Clarity Workflows v0.6.0 Chunk 4 candidate package in ChatGPT Library. They are retained as provenance records for the source archive, compiled candidate artifacts, and allowlisted source-file inventory.

The `files.sha256` paths retain the candidate archive's original top-level directory. The GitHub repository intentionally places that directory's contents at repository root, so the sidecar is an evidence record rather than a direct root-relative `sha256sum -c` manifest.
